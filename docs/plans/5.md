## Risks

- A public PR must never execute code on the self-hosted runner: only default/base workflows and scripts execute; PR trees are fetched as git objects and read as data.
- A PR must not weaken its own check: extract scripts with `git show origin/main:.ai-sdlc/...`; absence is an error. The adoption PR must merge before these checks can gate a subsequent PR.
- Revoked review must overwrite an earlier success: retain upstream per-head serialization and status writes for success, failure and errors, including edited/deleted comments.
- Preserve `checks / ...` job names by retaining a reusable caller job named `checks`; read-only release evidence defaults depend on these names.
