## Chosen fix

Vendor the MIT-licensed `braces` 3.0.3 runtime inside `client/vendor/braces`.
Keep its original package name and version. Add a hard maximum nesting depth of 100.
Guard both brace and parenthesis parsing and the three recursive AST processors.
Reject cyclic parent chains during AST expansion instead of allowing an endless walk.
Preserve all other upstream parsing and output behaviour.

Use a direct development dependency and an npm override to route every transitive `braces` consumer to this local package.
Retain `fill-range` as the runtime dependency. Remove upstream development dependencies and scripts from local package metadata.
The local package stays private and has no lifecycle scripts.

The advisory is [GHSA-vfj7-8cjw-p6xm](https://github.com/advisories/GHSA-vfj7-8cjw-p6xm).
The registry still publishes vulnerable 3.0.3 with no patched release.
The patch derives only from the depth guards in upstream PR 72, with local fixed bounds.
A renamed dependency or a zero audit result is not evidence of repair.
Local file dependencies can fall outside registry advisory matching, so record that limitation with the actual raw audit result.
Frozen regression tests and review of the installed patched source prove this local remediation.

## Risks and proof

- A partial guard could leave an alternate path vulnerable. Test brace, parenthesis and mixed strings plus direct compile, expand and stringify ASTs.
- A native stack overflow could resemble deliberate rejection. Assert the explicit depth-limit error in a child process with a deadline and bounded output.
- Transitive consumers could retain another package copy. Resolve from micromatch and chokidar, and require both to use the reviewed local package.
- Compatibility could affect appearance. Keep repository-controlled globs unchanged, test ordinary escaped/quoted/range patterns and compare exact generated CSS bytes.
- Local package metadata could pull in obsolete upstream development tooling. Omit development dependencies and scripts, then prove clean `npm ci` installs only the runtime dependency graph.
- Audit tools may omit local packages. Keep the original identity/version and disclose that limitation. Never claim an upstream advisory has been withdrawn.
- This fixes the specified nesting/stack-exhaustion defect. It does not claim a universal bound on expansion cardinality or arbitrary malformed JavaScript objects.
