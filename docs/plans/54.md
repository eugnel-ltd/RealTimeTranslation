Intent: RTT #54. Task type: bug-fix/security, level2; no spending, deployment or configuration changes. The independent reviewer reproduced a signed Access request with a customer session from a sibling site opening the paid Gemini upstream. ## Change

Reject `null`, empty, malformed, cross-site, sibling, scheme/port differences, path-bearing and coalesced/duplicate values with a fixed403 response before constructing `WebSocketPair` or calling a provider. Do not use forwarded host/origin headers, wildcard matching, suffix matching or browser account hints as authority. Preserve an absent Origin for legitimate nonbrowser Access clients, and preserve exact same-origin handshakes.

Keep the router's existing Access and rate-limit ordering, keys, model setup and frame handling unchanged. The check belongs in the shared Gemini handler so both owner and customer modes use it.
