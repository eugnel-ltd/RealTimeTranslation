## Review correction

Independent review found that Playwright browser routing does not intercept redirect targets after `route.continue()`. Frozen real-command regression `e4ca6b8` uses two loopback servers: the original command sent one request to the other origin, failing the explicit zero-request assertion. The fix fetches local assets with `maxRedirects: 0`, refuses every 3xx and stops before accepting screenshots when a request was refused. This extends the plan with `tests/listing-capture-redirect.mjs`; its assertions remain unchanged. No external host was contacted for the proof. The direct test uses the same installed browser tools as capture; it is a separate browser check, not part of the provider-free Vitest suite.
