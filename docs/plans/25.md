## Risks

- A valid JSON object can contain non-string language values and trigger `.strip()` errors during recognition startup. Validate each field, keeping other valid fields and the established defaults.
- Missing/unreadable/malformed/non-object files must keep startup usable. Do not touch the actual user's settings in tests.
- Writing directly to the destination can destroy the last valid record on partial-write failure. Write and flush a sibling temporary file, replace the destination only after successful completion, and clean up failed temporary files.
- A save failure must not escape the Tk callback or roll back usable in-memory settings. Use the existing error text area; preserve the settings window's current behavior and exact widget/style/layout blocks.
