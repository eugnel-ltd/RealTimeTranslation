# Web listing material

[web.json](web.json) holds the current web copy and [the candidate release note](../../releases/1.0.0.md) supplies its change text. The app remains free and owner-only. Neither file claims a public launch or a deployed version.

The screenshots show the existing local production build, at 1440 × 1000 and 390 × 844 viewports, with one explicitly synthetic saved transcript. They do not show provider output, a real account or a live release. The capture fixture explicitly selects the disabled-account owner interface; it does not exercise customer sign-in. Captions and source/build hashes are in [screenshots/capture.json](screenshots/capture.json). The capture preserves the interface without image composition.

To reproduce, build with `npm ci`, `npm --prefix client ci` and `npm run build`, then serve `client/dist` on a loopback-only HTTP server. Run `node scripts/capture-listing.mjs http://127.0.0.1:PORT`. The script needs an installed Playwright module and Chromium; cloud sessions can set `PLAYWRIGHT_MODULE=/opt/codex/cua_node/lib/node_modules/playwright-core/index.mjs` and `CHROMIUM_EXECUTABLE=/usr/bin/chromium`. The script uses these tools only for capture. Use a clean committed source for accepted captures. The script blocks requests outside the selected loopback origin, writes and unexpected APIs; config and empty profiles are synthetic local fixtures. The script never starts recording. Run `node tests/listing-capture-redirect.mjs` with the same browser environment to check that redirects cannot reach another origin. It needs an existing build; both proof servers bind only to loopback.

The listing reuses the existing [generic microphone glyph](assets/microphone.svg) from Heroicons v2.2.0. Its two paths match the `MicrophoneIcon` already used by RTT's Start button. The SVG is copied unchanged under the owner's instruction to reuse what exists, with the full [MIT notice](assets/HEROICONS-LICENSE.txt) and [immutable source and byte hashes](../../provenance/listing-icon.json). It is not a custom RTT brand mark. No new design, app icon, favicon, style or screenshot change is made. Vite's placeholder logo is not used as RTT's icon.

Before public use, refresh the screenshots against the actual verified release and record that release's SHA, version and health evidence. Issues #9 and #11 track the legal routes and support evidence; listing paths and the reused glyph alone do not prove they are live.
