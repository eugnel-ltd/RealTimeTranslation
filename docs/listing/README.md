The screenshots show the existing local production build, at 1440 × 1000 and 390 × 844 viewports, with one explicitly synthetic saved transcript. Captions and source/build hashes are in [screenshots/capture.json](screenshots/capture.json). The capture preserves the interface without image composition.

To reproduce, build with `npm ci`, `npm --prefix client ci` and `npm run build`, then serve `client/dist` on a loopback-only HTTP server. Run `node scripts/capture-listing.mjs http://127.0.0.1:PORT`. The script needs an installed Playwright module and Chromium; cloud sessions can set `PLAYWRIGHT_MODULE=/opt/codex/cua_node/lib/node_modules/playwright-core/index.mjs` and `CHROMIUM_EXECUTABLE=/usr/bin/chromium`. The script uses these tools only for capture. Use a clean committed source for accepted captures. The script blocks requests outside the selected loopback origin, writes and unexpected APIs; config and empty profiles are synthetic local fixtures. The script never starts recording. Run `node tests/listing-capture-redirect.mjs` with the same browser environment to check that redirects cannot reach another origin. It needs an existing build; both proof servers bind only to loopback.
